# 0001 — Adotar ADRs

Data: 2026-10-13. Status: aceito.

## Contexto
O novo Ipebook precisa preservar decisões e suas razões, conforme as instruções globais.

## Decisão
Usar documentos Markdown numerados em `docs/adr`, com título, data, status, contexto, decisão e consequências. Referência: https://github.com/architecture-decision-record/architecture-decision-record.

## Consequências
Decisões relevantes ganham histórico verificável. Mudanças triviais não exigem registros. Usar somente README foi descartado porque não preserva facilmente decisões substituídas.
