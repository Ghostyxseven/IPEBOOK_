# NavigationBar

Barra de navegação inferior com os cinco destinos do app.

- Destinos fixos: Início, Explorar, Estante, Conversas e Perfil (decisão de 02/10/2026, igual no Android e no iOS).
- Item ativo com pílula `secondary-container`; rótulos sempre visíveis.
- Badge em Conversas entra no rótulo acessível ("Conversas, 3 não lidas").
- No iOS use a tab bar oficial de vidro do iOS 26 com os mesmos destinos.
