# BookCover

Capa ilustrativa gerada quando o anúncio ainda não tem foto.

- Cinco cores (`cover-navy`, `cover-brown`, `cover-forest`, `cover-wine`, `cover-ochre`) e quatro motivos; sol em `cover-sun`, texto em `cover-on`.
- Proporção 120:170. A partir de 80 px mostra autor e título; em 44 px (listas) só a arte.
- Escolha cor e motivo pelo id do anúncio, para a capa não mudar entre telas.
- Esta prévia simplifica os motivos; a arte final está no Figma (Capa ilustrativa).
