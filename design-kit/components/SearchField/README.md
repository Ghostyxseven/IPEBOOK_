# SearchField

Campo de busca em pílula de 56 px para Início e Explorar (Android e Web).

- Fundo `surface-container-high`; placeholder diz o que dá para buscar.
- Com texto, mostra o botão Limpar (rótulo acessível "Limpar busca").
- Rótulo acessível "Buscar livros" mesmo sem rótulo visível.
- No iOS use o campo de busca nativo da barra (Tab de busca).
