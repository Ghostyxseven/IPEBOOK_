# EmptyState

Estado vazio que ocupa o lugar da lista quando não há conteúdo.

- Para Estante, Favoritos, Conversas, Notificações e busca sem resultado.
- Título na serifa (`brand-card-title`), texto que diz o próximo passo e no máximo uma ação Contornada.
- A barra superior e a navegação continuam visíveis: não é tela inteira.
