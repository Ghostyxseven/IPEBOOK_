# Dialog

Diálogo do Material 3 para confirmar ações que não dá para desfazer ou que avisam outra pessoa.

- Título em pergunta curta; o texto diz a consequência; ações à direita, a de confirmar por último e com verbo (nunca "OK").
- `destructive` usa o botão Perigo.
- Scrim `scrim` atrás. O foco vai para o diálogo ao abrir e volta ao gatilho ao fechar; Esc e voltar cancelam.
- No iOS use o alerta oficial.
