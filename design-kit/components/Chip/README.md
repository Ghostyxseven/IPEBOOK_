# Chip

Chip de filtro de 32 px para modalidade, gênero e distância.

- Selecionado: `secondary-container` com check (o check também sinaliza a seleção sem depender da cor).
- Não selecionado: borda `outline`. Desabilitado: 12%/38%.
- Use para filtrar. Metadados do livro (estado, gênero, bairro) são texto, não chips.
